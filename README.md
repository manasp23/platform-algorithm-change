# platform-algorithm-change
# When the Platform Changes What It Rewards
Algorithmic objectives and the reallocation of attention on Roblox

**Manas Paul**, PhD student, Information Systems, College of Business,
University of Texas at Arlington. Contact: mxp3736@mavs.uta.edu

## Summary
In April 2026 Roblox retuned its "Recommended For You" feed toward
longer-horizon retention. This project asks which games gained and lost
player attention when the recommender's objective changed, and how
creators responded. The design is a continuous-dose difference-in-
differences with a weekly event study on a panel of about 7,600 Roblox
games (six-hourly concurrent players, average playtime and favorites,
mid-2020 to present). Fortnite Creative and UEFN islands, which were not
exposed to the Roblox change, serve as a genre-matched cross-platform
control group. The work is a term paper for INSY 6307 (Fall 2026) and is
intended for journal submission.

## Data
- Roblox game panel: Rolimon's, private, used with written permission.
- Fortnite Creative island statistics: FN360.gg, used with permission
  for academic research and credited as the data source.

No raw data, exports or API credentials are stored in this repository.
Data are not redistributed.
